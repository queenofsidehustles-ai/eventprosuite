# Party Biz Hub

**The back office built for party-business owners.** Quotes, contracts, a profit
calculator, AI content, event prep, and a build-your-own website — all in one place.

🌐 **Live:** [partybizhub.com](https://partybizhub.com) · **From $27/month**

---

## What it does

Party businesses had no industry-specific software — generic CRMs were too broad and
spreadsheets were manual and error-prone. Party Biz Hub gives owners one place to run
the whole workflow: quote a party, send a contract, prep the event, track profit, and
market the business.

| Feature | What it does |
|---------|--------------|
| **Quote Builder** | Dynamic, professional quotes with line items and packages |
| **Contract Generator** | 6-step wizard with a client-facing signing page |
| **Profit Calculator** | Per-event → monthly → yearly financial rollups |
| **AI Content Engine** | Generates on-brand social posts, captions, and marketing copy |
| **Build-Your-Own Website** | Each owner gets their own bookable site |
| **Event Prep Pro** | Prep checklists and shopping lists with PDF export |
| **Vendors Directory & My Quotes** | Supplier list and quote status tracking |

## Tech

- Front end: static HTML + JavaScript
- Serverless API (`/api`) with AI content via OpenRouter
- Data & auth: Supabase · Payments: Stripe
- Hosted on **Vercel**
